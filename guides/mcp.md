# MCP

## AIへの指示
MCPの利用について以下のルールを厳守してください。

### Github
- `github.com`のURLが与えられた場合、ブラウザでアクセスせず、github MCPを利用してください
- github MCPが利用できない場合は、ghコマンドを利用してください

### JIRA
- `atlassian.net`のURLが与えられた場合、ブラウザでアクセスせず、環境で利用可能なAtlassianのMCPを利用してください
  - 例: `atlassian-v2` MCP、Atlassianプラグインが提供するMCP
- 利用可能なAtlassianのMCPがない場合は、ユーザーに確認してください
