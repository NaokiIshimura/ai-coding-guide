## 概要

markdownファイルの入出力を行います。作業状況の出力（output）や、過去の作業履歴の読み込み（input）を実行できます。

## コンテキスト

- 現在のブランチ: !`git branch --show-current`
- 現在のディレクトリ: !`pwd`
- 現在の日時（日本時間）: !`TZ=Asia/Tokyo date +"%Y-%m-%d %H:%M:%S"`
- ファイル名用タイムスタンプ（日本時間）: !`TZ=Asia/Tokyo date +%Y_%m%d_%H%M_%S`

## 対応操作

### 1. 出力（output）

現在までの作業状況や調査結果を整理して、構造化されたmarkdownファイルとして出力します。

**出力先:**
- チケット番号あり: `.claude/plans/<チケット番号>/`
- チケット番号なし: `.claude/plans/tmp/`
- ユーザーが出力先を指定した場合はそのパス

**ファイル名形式:**
- パターン: `YYYY_MMDD_HHMM_SS_<トピック>.md`
- タイムスタンプは日本時間（`TZ=Asia/Tokyo date +%Y_%m%d_%H%M_%S` で取得）
- 例: `2025_1018_1430_00_api-investigation.md`

**実施手順:**

1. **出力内容の確認**
   - 出力したい内容（作業状況、調査結果、実装計画、課題リストなど）、トピック名、出力形式を確認
   - 指定がない場合は会話の内容から判断する
2. **情報の収集と整理**
   - 現在の作業状況を分析
   - 関連するファイルや変更内容を確認
   - git差分がある場合は変更内容を要約
3. **ファイルの出力**
   - 出力先ディレクトリが存在しない場合は作成
   - 既存ファイルとの重複をチェック
   - ファイル末尾は空行で終える
4. **出力完了の報告**
   - 出力したファイルのパス
   - 主要なセクションや内容の要約

**ドキュメント構成:**
```markdown
# [タイトル]

## 概要
- 作業の目的や背景
- 調査の対象や範囲

## 実施日時
- 開始日時
- 完了日時（進行中の場合は現在日時）

## 作業内容 / 調査結果
### [セクション1]
- 詳細な内容

## 成果物
- 作成・変更したファイル一覧
- 主要な変更内容

## 発見事項・課題
- 発見した重要なポイント
- 解決すべき課題

## 参考情報
- 参照したドキュメント
- 関連するリンク

## 次のステップ
- 今後実施すべき作業
```

**出力オプション:**
- 出力形式
  - `standard`: 標準的な作業レポート形式（デフォルト）
  - `investigation`: 調査レポート形式
  - `plan`: 実装計画書形式
  - `summary`: 簡潔なサマリー形式
- 詳細度
  - `brief`: 簡潔な要約のみ
  - `normal`: 通常の詳細度（デフォルト）
  - `detailed`: 詳細な情報を含む

### 2. 入力（input）

指定ディレクトリ内のmarkdownファイルを読み込み、過去の作業状況を把握します。

**読み込み対象:**
- 引数指定あり: 指定されたパス（例: `.claude/plans/ABC-123/`）
- 引数指定なし: `.claude/plans/`（デフォルト。配下のサブディレクトリを含む）

**実施手順:**

1. markdownファイル（.md）を検索し、タイムスタンプ順（新しい順）に並べる
2. ファイル数に応じて読み込み方法を切り替える
   - 10件以下: すべてのファイルを直接読み込んで分析
   - 10件を超える: Agent ツールで組み込みの `Explore` エージェントを起動し、各ファイルの主要情報の抽出を任せてメインのコンテキストを節約する。エージェントが返した情報を統合する
3. 各ファイルの主要情報を抽出:
   - タイトルと概要
   - 実施日時
   - 作業内容/調査結果の要約
   - 発見事項・課題
   - 次のステップ
4. ファイル間の関連性や時系列での変化を分析し、情報を統合・要約する
5. サマリーと次のアクションの提案をユーザーに提示する

**出力形式:**
```markdown
# 過去の作業状況サマリー

## 読み込んだファイル一覧
1. [ファイル名] - [日時] - [トピック]

## 時系列での作業履歴
### [日付1]
- 実施した作業
- 主要な成果
- 発見した課題

## 主要なトピック別整理
### [トピック1]
- 関連する作業内容
- 進捗状況
- 残課題

## 未解決の課題・継続タスク
- 課題1: 詳細と優先度

## 次に取り組むべき項目
1. 優先度の高い項目

## 参考情報
- 読み込んだファイルへのパス
```

## 注意事項

- 機密情報（パスワード、APIキー、トークン等）は出力しない
- タイムスタンプは日本時間を使用
- 構造化された読みやすいフォーマットを使用し、コードブロックには言語を指定する
- 関連ファイルやドキュメントへは相対パスで参照する
- 読み込みエラーが発生したファイルはスキップして次のファイルへ進み、スキップしたことを報告する

## タスク

ユーザーの指示に基づいて、markdownファイルの入出力操作を実行してください。

出力時は内容を確認し、入力時は統合した情報をわかりやすく提示してください。
